# Shrey Shah — Portfolio

A responsive, interactive, minimalist personal portfolio inspired by the ideas of continuous improvement, intentional space, and understatement. No Lovable credits or hosting subscription required.

## Tech stack

Plain **HTML, CSS, JavaScript** (no build step, no backend, no dependencies), ready for **Cloudflare Pages** with GitHub Git integration.

This is a deployable version of the reviewed prototype. The separate React + Vite source from the previous review remains available if the site later expands substantially.

## Edit content

- `index.html`: name, sections, contact and social URLs, SEO metadata
- `styles.css`: typography, colors, layout, transitions, responsive breakpoints
- `script.js`: navigation and scroll interactions
- `favicon.svg`: site icon

## Preview locally

Open `index.html` directly in a browser, or from this folder run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Read `DEPLOY_GUIDE.md` for GitHub + Cloudflare Pages + domain DNS instructions. The GitHub repository should contain **the extracted files**, not the `.zip` archive.
